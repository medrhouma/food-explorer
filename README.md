# FoodExplorer 🍕

Application Android moderne de recettes avec Jetpack Compose

## 📱 Fonctionnalités

- 🏠 Liste de recettes populaires
- 🔍 Recherche par nom ou ingrédient
- ⭐ Favoris avec stockage local
- 🍽️ Navigation par catégories
- 📖 Détails complets des recettes

## 🛠️ Technologies

- Jetpack Compose
- Navigation Compose
- Retrofit (API TheMealDB)
- Room Database
- Architecture MVVM
- Material 3

## 🚀 Installation

1. Cloner le repository
2. Ouvrir dans Android Studio
3. Sync Gradle
4. Lancer l'application
